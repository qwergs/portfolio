# 스마트 항만 무인 운반차 경로 최적화

FKII 스마트 해운물류 x AI 미션 챌린지 (2025), 5명 팀. 14위 / 229팀 (상위 6%).

짐 무게, 이동 거리, 마감 시간을 지키면서 여러 무인 운반차(AGV)의 작업 배정과 경로를 정하는 문제입니다.

팀원마다 각자 풀이를 만들어 비교한 뒤 가장 좋은 결과를 낸 풀이를 제출했습니다 (제출한 풀이는 다른 팀원의 코드).

- 제출 풀이: 간단한 규칙으로 처음 해를 만들고, 담금질 기법(simulated annealing)과 ruin-and-recreate로 해를 개선
