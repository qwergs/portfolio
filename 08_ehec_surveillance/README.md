# 장출혈성대장균(EHEC) 24년 신고 추세 (2001–2024)

Lee G, Kim S, Ha C. *Foodborne Pathogens and Disease*, 리비전(R2) 중. 제1저자.
데이터와 코드: https://doi.org/10.5281/zenodo.23357245

다른 장 감염병은 줄어드는데 EHEC 신고만 늘어난 이유가 검사 확대 때문인지 확인했습니다.

- 신고 2,465건, 음이항 회귀로 연간 증가율 추정
- 같은 신고 체계를 쓰는 세균성이질과 장티푸스에 같은 모형을 적용해 비교
- 추세가 바뀌는 시점 탐색, 시도별 지역 군집 분석

결과: 연 약 10% 증가 (2001년 10건, 2024년 274건), 비교 질환은 연 12.1%, 7.3% 감소. 리비전 중 직접 찾은 분석 오류는 심사위원에게 알리고 수정했습니다.

파일: `scripts` (분석·그림), `data` (집계 자료), `Supplementary_Material.pdf`
