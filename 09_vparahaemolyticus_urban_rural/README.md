# 장염비브리오 식중독과 바다 수온 (2011–2024)

Lee G, Kim S. *Zoonoses and Public Health*, 심사 중. 제1저자.

장염비브리오 식중독 1,440건을 229개 시군구 단위로 분석했습니다.

- 지역 특성 21가지를 넣은 베이지안 모형(R-INLA)에 과적합 방지 장치 추가
- 해안 시군구의 월별 발생을 바다 수온과 비교

결과: 해안 시군구 발생률 2.45배, 바다 수온이 1 °C 오를 때마다 발생 34% 증가. 과적합을 막자 소득·의료 같은 지역 요인과의 관련성은 사라졌습니다.

심사 중이라 코드와 자료는 게재 후 올릴 예정입니다.
