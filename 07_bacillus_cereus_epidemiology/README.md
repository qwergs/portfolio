# 바실러스 세레우스 식중독 도시·농촌 분석 (2011–2024)

Lee G, Kim S. *International Journal of Environmental Health Research*, 2026. 제1저자.
논문: https://doi.org/10.1080/09603123.2026.2739935 · 데이터와 코드: https://doi.org/10.5281/zenodo.22787269

식약처 식중독통계의 바실러스 세레우스 1,223건을 229개 구·군 단위로 분석했습니다.

- 구·군-연도의 약 97%가 0건인 자료라 0이 많은 자료에 맞는 베이지안 모형(ZINB, R-INLA) 사용
- 지역 군집이 없어(Moran's I = −0.005) 공간 모형 대신 단순한 모형 선택
- 심사 과정에서 다른 모형으로 재확인, 자료 집계 오류를 찾아 고친 뒤 재분석 (결론 동일)

결과: 농촌 발생률이 도시의 3.7배, 농경지 이용과 개인 지하수 사용이 위험과 관련
