# 교권 침해 설문 분석

KOSSDA 대학생 데이터 시각화 공모전 2026, 2명 팀 (관광데이터 공모전과 같은 팀). 데이터 수집·전처리와 보고서 작성을 맡았습니다.

교사 10,888명이 응답한 교원 인권상황 실태조사(2024)로 학교 환경, 교권 침해, 정신 건강, 이직 생각 사이의 관계를 분석했습니다.

- 로지스틱 회귀로 침해 위험이 큰 학교 유형 확인
- 구조방정식(SEM)과 매개 분석으로 침해가 정신 건강을 거쳐 이직 생각으로 이어지는지 확인
- 군집 분석으로 교사 유형 구분
