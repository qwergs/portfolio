# FIELD: 금융 성향 군집과 자산 배분

대한산업공학회 동아리 연합 전국 대회 과제 (2025, 팀원으로 참여).

- 1단계: 가구 조사 자료를 정리하고 PCA + DBSCAN으로 금융 성향 유형을 나눔
- 2단계: 암호화폐, 국고채, ETF, 주식으로 자산 풀을 만들고 Markowitz, Black-Litterman, Risk Parity, 동일 비중 등 배분 방법 비교

파일: `phase1_clustering.ipynb`, `phase2_modeling.ipynb`, `phase2_portfolio_optimization.ipynb`
