# FIELD 캠프: 금융 성향 유형 분석

대한산업공학회 2박 3일 캠프 (2025), 9명 팀. 세 문제 중 금융 페르소나 구축을 맡아 변수 선별, 군집 분석, 유형 해석과 발표를 했습니다.

- 1단계 (본인 담당): 가구 조사 자료에서 변수를 골라 PCA + DBSCAN으로 금융 성향 유형을 나누고 해석
- 2단계 (다른 팀원 담당, 팀 코드로 함께 보관): 암호화폐, 국고채, ETF, 주식으로 자산 풀을 만들고 Markowitz, Black-Litterman, Risk Parity, 동일 비중 등 배분 방법 비교

파일: `phase1_clustering.ipynb`, `phase2_modeling.ipynb`, `phase2_portfolio_optimization.ipynb`
