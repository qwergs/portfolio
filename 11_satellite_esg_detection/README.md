# 위성영상으로 대기오염 배출원 찾기

데이터 크리에이터 캠프 2025 대학부 (K-ICT 빅데이터센터), 팀 NBD 4명, 팀장. 산업단지 영역 나누기(미션 3)를 맡았습니다.

AI-Hub 위성영상(Kompsat-3/3A, Sentinel-2)으로 세 가지 미션을 풀었습니다.

| 미션 | 모델 | 결과 |
|---|---|---|
| 굴뚝 찾기 | YOLOv8 | mAP@0.5 0.993 |
| 굴뚝 높이 예측 | ResNet | |
| 산업단지 영역 나누기 (본인 담당) | 4채널 U-Net | mIoU 0.91 (사전학습 모델 0.75) |

4개 채널을 그대로 쓴 U-Net이 일반 사진으로 미리 학습된 모델보다 좋았습니다.

파일: `mission3.ipynb`, `모델링코드.ipynb` (영역 분할), `mission2.ipynb` (높이 예측), `train/` (학습 코드), `train3/` (YOLOv8 결과)
위성영상 원본과 모델 가중치는 넣지 않았습니다.
