# 여행 일정 검사 웹 서비스

2026 관광데이터 활용 공모전 웹앱 부문, 2명 팀. 데이터 수집·전처리, 아이디어 정리, 제출 PPT와 보고서 작성을 맡았습니다.

여행 일정을 추천하는 대신, 이미 만든 일정이 실제로 가능한지 검사합니다.

- 데이터: 한국관광공사 TourAPI 관광지 34,442곳, 카카오 모빌리티 이동 시간
- 운영 시간·이동 시간·머무는 시간이 맞지 않는 일정을 찾아냄
- 과밀 일정, 돌아가는 동선 등 6가지 경고와 경로 수정 제안
- 판정은 규칙으로 하고, 결과 설명 문장만 LLM으로 생성

실행
```
# .env 파일에 TourAPI, 카카오 API 키를 넣은 뒤
docker compose up --build
```

파일: `src` (서비스 코드), `tests` (테스트)
