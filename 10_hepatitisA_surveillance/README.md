Lee G, Kim S. *Pathogens and Global Health*, 심사 중. 제1저자.

질병관리청에 신고된 A형간염 54,642건을 다시 분석했습니다.

- 증가·감소 추세 검정과 음이항 회귀, 추세가 바뀌는 시점 탐색
- 웨이블릿으로 계절 패턴 확인, 시도별 지역 군집 분석
- 인구 수 이중 집계 오류를 찾아 수정
